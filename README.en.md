# Mao Xiao Man (贸小满)

**A quotation and trade-document workspace for export sales teams.**

Mao Xiao Man helps prepare quotations (QT), pro forma invoices (PI), commercial invoices (CI), and packing lists (PL). Customer, product, and company details can be reused across documents.

[简体中文](README.md) · [Send feedback](https://github.com/maoxiaoman-org/maoxiaoman/issues/new/choose) · [Browse issues](https://github.com/maoxiaoman-org/maoxiaoman/issues)

## What it does

- Prepare four common trade documents, preview templates, and export A4 PDFs.
- Keep customer, product, and company details together to reduce repeated entry.
- Use a Simplified Chinese or English interface and choose from seven document language options.
- Store workspace data in the current browser, with JSON backup and restore.

There are currently no accounts or cloud sync. PDF export temporarily sends the selected document to the server for rendering; that document may include company, customer, product, and payment details. Other documents and records are not synced. Review all trade details before sending a document to a customer.
