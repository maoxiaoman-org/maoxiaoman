# 贸小满

**给外贸业务员的报价与单据工作台。**

贸小满帮助你整理客户、产品和公司资料，制作报价单（QT）、形式发票（PI）、商业发票（CI）与装箱单（PL），并在后续单据中复用已填写的信息。

[English](README.en.md) · [反馈问题](https://github.com/maoxiaoman-org/maoxiaoman/issues/new/choose) · [查看已有反馈](https://github.com/maoxiaoman-org/maoxiaoman/issues)

## 主要功能

- 制作四类常用外贸单据，预览模板并导出 A4 PDF。
- 管理客户、产品和公司资料，减少重复录入。
- 界面支持简体中文和英文；单据可选择英文、简体中文、中英双语、西班牙语、巴西葡萄牙语、法语或德语。
- 在当前浏览器保存资料，并通过 JSON 文件备份和恢复。

当前版本没有账号和云同步。生成 PDF 时，当前单据会发送到服务器临时处理，其中可能包含公司、客户、产品及收款信息；其他单据和资料库不会因此同步。实际交易中的字段、金额和条款，请在发送前自行核对。

## 反馈与交流

欢迎通过 [Issues](https://github.com/maoxiaoman-org/maoxiaoman/issues/new/choose) 报告问题、提出建议或咨询使用方式。提交 Issue 需要 GitHub 账号。请说明遇到问题的页面、操作步骤和预期结果，方便定位。

**请勿在公开 Issue 中发布真实客户信息、报价、单据、银行资料、账号凭据或未打码的截图。**
